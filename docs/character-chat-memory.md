# Character Chat の記憶設計

Character Chat の記憶は、会話全文を長期記憶として複製しない。

## 1. キャラ設定

キャラクターの性格、話し方、背景、好み、会話ルールは `characters.system_prompt` にまとめる。
これは全Storyに共通する固定設定であり、Storyを削除しても消えない。

以前の `memory_text` は起動時に `system_prompt` の補足設定へ一度だけ移行され、以後は独立した長期記憶として扱わない。データベース上の旧カラムは既存データ移行のために残しているが、新しいAPIとUIでは使用しない。

## 2. Storyの長期記憶

Storyごとに `conversation_memories` を持つ。記憶は次のような短い確認済みメモであり、メッセージ本文のコピーではない。

- `summary`: Codex CLIがStory全体から生成する自動要約。Storyにつき最新1件を保持
- `fact`: 起きた事実
- `relationship`: 登場人物同士の関係
- `setting`: Story固有の設定
- `goal`: 目的や約束
- `preference`: このStory内での好み

通常はStory画面の「記憶」ボタンを押し、確認ダイアログで「はい」を選ぶ。Codex CLIがStory全体を読み、将来必要な事実だけを短く要約して、自動要約メモを更新する。会話を続けてから再度実行すれば、自動要約は置き換えられる。会話中の「＋ 記憶に追加」または記憶画面から、手動メモを追加することもできる。

この方式は、会話を長期記憶へ全文コピーするより軽く、何を覚えているか確認・編集・削除できる。自動要約はCodex CLIが生成するが、保存されるのは要約結果だけであり、既存の手動メモは置き換えない。自動更新はCodex backendが必要で、mock backendでは実行しない。

## 3. Story削除

Story削除では、次を同時に削除する。

- Story本体とStory設定
- Story内のメッセージ
- Storyの参加キャラクター関係
- Story専用の `conversation_memories`

キャラクターの `system_prompt` とユーザーPersonaはStory共通データなので削除しない。

## 4. Agentへ渡す情報

1. ユーザーPersona
2. Story設定（Plot、ジャンル、POV、テンポ）
3. Storyの確認済み長期記憶（存在する場合だけ）
4. 参加キャラクターのキャラ設定
5. 直近24メッセージ
6. 今回だけの追加指示

自動要約の更新時だけは、要約生成のためにそのStoryのメッセージ全体を一時的にCodex CLIへ渡す。これは長期記憶として保存するためではなく、要約を作るための入力である。

直近メッセージは会話の流れを維持するための短期コンテキストであり、長期記憶とは別物である。
