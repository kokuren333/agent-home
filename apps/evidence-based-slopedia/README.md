# Evidence Based Slopedia (EBS)

EBSは、信頼できるソースを調査し、引用と限界を含む記事を生成・保存する知識ポータルです。このディレクトリは `agent-home` に組み込まれたEBSアプリのソースです。

## 現在のランチャー統合版

- 画面入口: `ui/index.html`
- ランチャーから起動し、画面上部の「Launcherへ戻る」でランチャーへ戻る
- 記事のフリーワード検索は上部の検索フォームから行う
- 記事作成、今日のニュース生成、キュー確認・削除は画面下部から行う
- キューと生成状態はagent-home GatewayのSQLiteで管理する
- Codexによる調査・執筆、画像生成、記事とPNG画像の保存をGateway経由で行う
- 記事の参考ソースは、公開後にブラウザから開けるリンクとして保存する
- Forecast/占い画面、Topics機能、WebP変換、GitHub Pagesへの自動公開は現行アプリにはない

## 起動と利用

リポジトリのルートでGatewayを起動します。

```powershell
npm install
$env:AGENT_BACKEND = "codex"
npm start
```

Codexを使わず画面とキューの動作だけ確認する場合は、`AGENT_BACKEND=mock` を指定します。起動後、ランチャーでEBSを選択してください。スマホからの接続方法はルートの [README](../../README.md) と [Tailscale手順](../../docs/tailscale.md) を参照してください。

## 生成の流れ

1. 下部の記事作成フォームまたは今日のニュース生成からキューへ登録する。
2. Gatewayのワーカーがキューを順に処理する。
3. 信頼できるソースを調査する。
4. EBSの指定フォーマットで記事本文と参考ソースを作成する。
5. imagegenで記事画像をPNGとして生成する。
6. 記事Markdownと画像を保存し、完了状態にする。

処理中はキューに段階（待機中、ソース調査中、記事作成中、画像生成中、保存中、完了、失敗）を表示します。登録時刻も表示されます。

## データの保存場所

キューや実行履歴はGatewayのSQLiteに保存されます。生成された記事、画像、ログなどの個人データ・派生成果物はGitに含めません。詳細な除外規則はルートの `.gitignore` を参照してください。

## 旧EBS資料と旧自動化

このディレクトリには、元のEBSリポジトリから移植した編集規約、記事データ、調査資料、スキル、監査レポートが残っています。これらは記事品質の参考資料であり、ランチャーの実行経路そのものではありません。

`automation/discord_bot/` と `automation/ebs/` は旧EBS単体運用のコードです。ランチャー統合版からは呼び出されません。Discord、Forecast、WebP、GitHub Pagesを使う旧手順は、現行ランチャーの起動・運用手順として扱わないでください。

文書の現行性は [docs/README.md](docs/README.md) にまとめています。アプリ規格は [ルートのアプリプロトコル](../../docs/app-protocol.md)、ランチャーへの追加方法は [アダプターガイド](../../docs/app-adapter-guide.md) を参照してください。

## 開発時の確認

変更後はリポジトリのルートで次を実行します。

```powershell
npm run build
npm test
```

EBS固有の旧スクリプトを実行する場合は、それがランチャー統合版の処理ではないことを確認し、個人データや認証情報をリポジトリへ追加しないでください。
