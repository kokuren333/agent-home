# 旧EBS Discord Bot（参考実装）

このディレクトリのDiscord Botは、元のEBSリポジトリに含まれていた単体運用用の旧実装です。agent-homeのランチャー統合版からは起動されず、現在のEBSキュー、記事生成、画像生成、保存経路にも接続されていません。

## 現行利用者への案内

ランチャーでEBSを使う場合は、リポジトリルートからGatewayを起動し、EBS画面を開いてください。起動方法と現行の生成フローは [EBSアプリREADME](../../README.md) を参照してください。

この旧Botの手順にあるDiscordコマンド、Forecast、WebP変換、GitHub Pages公開、Vault固有のパスは、現行ランチャーの機能ではありません。現行環境の設定や認証情報をこのBot用に追加する必要もありません。

## 旧実装を調査・再利用する場合

旧Botを独立して動かす場合だけ、このディレクトリのソースと `.env.example` を確認してください。`.env`、Discord token、GitHub token、Codex認証情報、個人用パスは作成・保存・コミットしないでください。旧実装の出力先や公開処理は、現行Gatewayのデータ管理とは別に扱ってください。

このREADME以外の旧Bot関連文書・コメントは、元リポジトリの単体運用を説明する履歴資料です。ランチャー統合版の仕様書としては使用しないでください。
